
# Bhram

**Know the link before you trust it.**

Bhram is a Python-based phishing website detection system designed to identify suspicious URLs and potential website impersonation.

Initially focused on Nepali digital payment platforms and banking services, Bhram analyzes website URLs using rule-based detection techniques and provides risk scores with explanations of suspicious indicators.

### Key Features

- URL analysis and risk scoring
- Lookalike domain detection
- Suspicious keyword identification
- URL structure analysis
- Nepal-specific trusted-domain database
- Explainable risk assessment

### Technologies

Python · JSON · Flask (planned) · pytest

### Project Status

Under Development

### Disclaimer

Bhram is an educational and security-awareness project. Its risk assessments are indicators, not guarantees of website legitimacy or maliciousness.
