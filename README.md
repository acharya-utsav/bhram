# Bhram

**Know the link before you trust it.**

Bhram is a phishing URL detection platform designed to identify suspicious and malicious links through transparent security analysis.

It combines rule-based detection, verified brand intelligence, threat intelligence and machine learning to provide understandable, evidence-based URL assessments.

## Project Vision

To develop an extensible phishing detection platform that helps users recognize potentially malicious links and make safer decisions online.

## Core Features

- URL validation and normalization
- Rule-based phishing detection
- Brand impersonation and lookalike detection
- Verified brand-domain intelligence
- Threat intelligence integration
- Explainable risk assessment
- REST API and web interface
- Machine learning-assisted detection (planned)

## Development Status

**Under Development**

Bhram is being developed incrementally, beginning with a Python-based URL inspection engine.

## Project Roadmap

1. Python foundation and URL inspection
2. Rule-based detection engine
3. Brand intelligence registry
4. REST API and web application
5. Threat intelligence integration
6. Machine learning detection
7. Cloud and DevSecOps
8. MLOps and production-style deployment

## Security Philosophy

Bhram prioritizes transparent detection, evidence-based findings, privacy and safe URL handling.

An unknown URL must never automatically be considered safe.

The initial detection engine will analyze submitted URL strings without visiting the websites.
